# PWG Chatroom

A responsive, cross-platform room chat. Run `npm install` then `npm start`; open http://localhost:3000. To chat across devices, deploy the whole folder to a Node.js host with WebSocket support and open its public HTTPS address on each device.

Rooms and messages are held in memory for the lifetime of the server. Profiles use a saved device identity without a password. This chat does not provide encryption; use it with people you trust and do not share sensitive information.
